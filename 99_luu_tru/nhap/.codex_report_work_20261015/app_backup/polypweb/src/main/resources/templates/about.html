01

Mục tiêu nghiên cứu

Nghiên cứu tập trung khảo sát phương pháp tích hợp VMambaBlock vào YOLO26-seg trong bài toán phân đoạn polyp trên ảnh nội soi. Website hiện chạy thật cả checkpoint YOLO26n-seg và YOLO26n-VMamba-seg trên cùng API contract.

Bài toán phân đoạn polyp

Xác định vùng điểm ảnh thuộc khu vực nghi ngờ polyp, tạo mask không gian thay vì chỉ dự đoán một nhãn cho toàn bộ ảnh.

02

Mô hình được khảo sát

Baseline

YOLO26-seg

Được dùng làm cấu hình tham chiếu để tổ chức các thí nghiệm và so sánh.

Khối tích hợp

VMambaBlock

Khối VSS/SS2D-inspired được nghiên cứu để khai thác phụ thuộc không gian dài hạn trên feature map mức cao.

Hiệu quả của biến thể tích hợp cần được đánh giá bằng thực nghiệm; giao diện không đưa ra kết luận vượt trội.

03

Quy trình hệ thống dự kiến

Kiến trúc mục tiêu tách lớp giao diện Java khỏi dịch vụ suy luận Python và lớp lưu trữ.

Trình duyệt
Spring Boot
Python AI API
Mô hình
MongoDB

Spring Boot gửi ảnh multipart tới FastAPI, registry chọn đúng checkpoint baseline hoặc VMamba để tạo mask và MongoDB lưu metadata cùng đường dẫn ảnh.

04

Công nghệ sử dụng

Java 17 Spring Boot Thymeleaf Bootstrap 5 MongoDB FastAPI + YOLO26n + VMamba
05

Giới hạn của phiên bản

  • Ảnh gốc và overlay được lưu trong storage cục bộ; chưa có object storage hoặc cloud.
  • Chỉ kích hoạt hai checkpoint nano YOLO26n-seg và YOLO26n-VMamba-seg; tám cấu hình còn lại chưa được nối vào API.
  • Đã có Spring Security và ownership; chưa có OAuth, JWT hoặc xác thực đa yếu tố.
  • MongoDB chỉ lưu đường dẫn tương đối và metadata, không lưu chuỗi Base64.
